# Agora da Malu

PWA calmo para capturar tarefas, estudos e lembretes — feito para a Malu usar no iPhone.

**App:** [https://jbr121.github.io/tdah/](https://jbr121.github.io/tdah/)

**Tutorial (passo a passo):** [TUTORIAL.md](./TUTORIAL.md)

## Resumo rápido

1. Abrir o link no **Safari**.
2. Compartilhar → **Adicionar à Tela de Início**.
3. Abrir pelo **ícone**.
4. Engrenagem → **Ativar avisos no iPhone**.

O tutorial completo está em [TUTORIAL.md](./TUTORIAL.md): instalar, avisos, captura, tipos, foco e o que fazer se travar.
